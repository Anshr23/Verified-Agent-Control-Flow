The Bug Hunt (v1 → v3)

v1: agent looped forever on ambiguous input (no exit from the clarify loop). Live: hit LangGraph's recursion limit. Formal: NuSMV liveness spec L1 came back false with a lasso counterexample.
v2: fixed the loop in the model — but a modeling artifact let a safety spec (S1, no destructive action without confirmation) fail on a decision-timing quirk in how the environment variable was randomized.
v3: fixed the randomization to only re-decide at the actual decision point. All 4 specs pass. Code was then updated to match, verified by a live pytest gate that shells out to NuSMV.
